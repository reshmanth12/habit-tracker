Cross-device sync

Connect a free Firebase project so this tracker shares the same data across your laptop, phone, and any other device. One-time setup, takes a few minutes.

1. Go to console.firebase.google.com and create a project (free tier).
2. In the project, open Build → Firestore Database and click "Create database" (start in test mode).
3. Click the gear icon → Project settings → scroll to "Your apps" → add a Web app → copy the firebaseConfig object shown.
4. Paste that config below, choose a private sync code only you know, and connect.
